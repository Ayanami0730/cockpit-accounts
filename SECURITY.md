# Security

Do not post tokens, auth files, account exports, conversation backups or raw logs in public issues. If reporting a suspected vulnerability, start with a redacted description of the affected version and behavior; use the repository's private vulnerability-reporting feature when available.

This local tool handles sensitive account state. Install only from a source you trust, review changes before upgrading, and keep backups private. Account exports may contain reusable credentials. Official client authentication formats and provider behavior can change independently of this project.

See README.md for storage locations and the limits of testing. No scanner or test suite provides an absolute guarantee that software is free of security defects.
